# 暨快跑 · 校园综合信息服务平台

顺路接一单，帮你送到手。

产品暂定名：**暨快跑**。定位为校园综合信息服务平台，覆盖校园取送、二手（闲置＋求购）和校园墙，暂不单设校园互助。平台提供信息、站内联系及相关交易支付，不提供验货、保真或赔付保障。二手与校园墙业务已形成初稿，上线顺序及未决细节仍待确定。项目工作目录保留为 `JIRUN`。

**交易原则：**二手由买方／求购方付款，确认收到后结算给卖方；付款占用数量、确认收到计为售出、取消退款成功释放占用。可售数量归零自动下架，进行中的交易保留。原取送流程可参考，配送专属细则不直接复制到二手或校园墙。

“顺路接一单，帮你送到手”作为取送模块宣传语，平台总宣传语待定。

当前阶段：业务澄清与低成本验证，尚未进入正式开发。
