# 暨快跑 · 下单与接单说明（草案）

日期：2026-09-21。用于业务讨论与页面文案，尚未发布。依据见[业务文档](business-v0.1.0.md)，法律来源见[法律法规参考](legal-references.md)。正常配送者先点已送达、用户再确认结算；特殊照片随已送达入队等三小时，到期未确认才平台代审，通过直接结算。

## 1. 用户下单前说明

付款前展示本单取送地点、物品与数量、总金额、服务时段、接单截止时间、最迟送达时间及交付方式。以下内容放在付款按钮前；动态码段落仅在需要即时配合时展示。

> **下单前请确认**
>
> **付款后等待接单。** 本单由接单配送者按约取送，付款不代表已经有人承接。截止仍无人接单，订单关闭并原路退款；退款进度可在订单中查看。
>
> **请准确填写取送要求。** 核对物品、数量、取送地点及交付方式。需要动态码等即时信息时，请在所选服务时段准备配合；接单后会通知您配送者预计到达的五分钟时间区间。
>
> **有变化先沟通。** 未接单可上调或下调配送费，也可取消，分别处理补款或退差额；接单后不得随意改价或改条件。双方均可发起变更请求，另一方同意后形成新约定。协商不成优先按规则取消，退款后可重新发布；普通已接单取消通常需双方同意，已取件先明确交接。需即时配合时，配送者按约到站请求并联系失败，等三分钟仍未配合且未取件，可按规则终止并原路退款。
>
> **优先送到您指定的位置，再确认接收。** 配送者实际送到后会点击“已送达”，您收到后点击确认，立即触发报酬结算。正常当面交付不要求拍照；需放置时应有您明确指定或同意的位置，不能擅自改放。
>
> **特殊情况先等待您确认，再由平台代审。** 实在联系不上等特殊情况，配送者点“已送达”时附位置照片和说明，订单进入待审队列并从提交成功起等待三小时。期间您确认就直接结算并退出队列；超过三小时仍未确认，平台才代审，通过后结算。到期不会自动付款，审核通过后也不再额外等待。您可在等待及代审期间提出异议，订单转异常处理；审核不通过不支付报酬。
>
> **遇到问题，优先双方沟通。** 您可以同时提交异常记录；协商不成优先按规则取消／重新发布，不承诺在线客服调解或自动替补。平台提供必要记录与协助，不提供额外物品保险或兜底赔付承诺，各方仍承担相应责任。配送费退款与物品损失赔偿分别处理。

确认项（默认不勾选）：**我已阅读取送服务说明及取消、结算与异常处理规则，已核对本单信息。**

放置或备用放置授权单独选择，不包含在上述通用确认中。建议提示：**“我同意将本单物品放在【具体位置】，配送者放置后拍照并通知我。”** 未选择则无该授权；修改位置需重新确认。示例位置为“T9 栋 503 寝室门外左侧”，不能只填写“附近”。

## 2. 配送者接单前说明

接单前展示本单物品与数量、取送地点、必要楼层和通行条件、总报酬、交付方式与最迟送达时间。需即时配合时填写五分钟预计取件区间；无需配合时跳过。

> **接单前请确认**
>
> **确认能够完成，再接单。** 请核对物品、数量、路线、通行条件和时限。资格须后台审核通过。按约送到用户指定位置后，请先点击“已送达”，再由用户确认接收并触发报酬结算；正常交付不强制照片。
>
> **需要配合，提前告知。** 需要用户提供动态码等信息时，请填写预计到达取件点的五分钟区间，接单成功会同步通知用户；预计时间变化请及时沟通。按约到站请求信息并尝试联系失败后，等待三分钟仍未获得配合且实际未取件，可按规则终止；已取件或用户已恢复有效配合，不适用该退出方式。
>
> **先沟通，再修改。** 接单后双方均可发起件数、价格或服务条件变更请求，另一方明确同意后才形成新约定；未同意不覆盖原条件。增加报酬需用户补款，减少报酬跟踪差额退款。协商不成优先按规则取消；已取件先交接，不能遗留物品或仅取消后重发。
>
> **按用户约定交付。** 正常交到用户手中不要求拍照。无法当面交付时，先联系用户；已有明确放置授权，或沟通取得同意后，才可放置并拍照。照片需能辨认本单物品和具体位置，例如寝室门牌号、楼栋标识或与放置点明确对应的固定标识物；仅拍包裹或附近地标不足以说明交付位置。
>
> **特殊情况点已送达并附照片，先等用户确认。** 实在联系不上等特殊情况，实际按约交付后，点击“已送达”并附位置照片及说明，进入待审队列，从提交成功起等三小时。期间用户确认即结算并退出队列；超过三小时仍未确认，才由平台代审，通过后直接结算。审核不通过、无人审核或有未解决异议不支付报酬。代审期间用户确认且无未解决异议同样可结算并关闭待审任务，实际到账进度以支付处理结果为准。
>
> **超时和违规影响接单资格。** 最终送达截止后宽限十五分钟，宽限结束既无有效确认或代审结果、也无及时提交的待确认送达记录时，自动限制接新单十五天，其他功能不受影响。及时提交的送达记录先待确认或核实，特殊照片满三小时后代审，不因用户未确认或代审耗时直接处罚。偷吃外卖、私自占有包裹等经核实纳入违规。累计两次有效违规封号，正常完成订单不清零；您可以提交申诉工单，由后台复核。
>
> **请保留必要记录。** 发生异常时及时告知用户并留存沟通和交付记录；已取件的物品须明确后续交接。平台提供必要协助，不替配送者承担其应承担的责任，也不提供额外兜底赔付承诺。

确认项（默认不勾选）：**我已核对本单条件，了解履约、十五分钟宽限、十五天接单限制、累计两次违规封号及结算规则，确认承接。**

## 3. 放置照片提示与到期代审

仅在经授权的放置交付中展示；正常当面交付不强制照片，也不要求为留证补拍人脸或摆拍物品。

> **请拍清物品和具体放置位置。** 照片中应能辨认本单物品，并通过寝室门牌号、楼栋／楼层标识或固定标识物判断放置地点。尽量让物品与位置标识出现在同一画面；不能同时拍清时，补充能对应同一放置点的近景、环境照片。避免拍摄无关人员、寝室内部和完整快递面单。

判断示例：

| 示例 | 是否足以说明位置 |
|---|---|
| 包裹与约定寝室门牌在同一画面，能够对应订单楼栋 | 可用于判断具体放置位置 |
| 放置点近景与楼栋／楼层环境照互相对应 | 可作为补充，不以固定照片张数替代信息完整性 |
| 只有包裹特写，没有位置参照 | 不足，需要补充位置照片 |
| 只拍附近楼栋或地标，看不到物品实际放在哪里 | 不足，附近标识不能代替实际放置点 |

照片关联本单送达记录，供本单双方及有必要权限的处理人员查看，不进入公开大厅。照片是交付凭证之一，不单独保证事实已查清。丢件时平台可协助联系校方、按程序申请查阅相关监控，不承诺直接调取或必然取得录像。

特殊流程：点“已送达”并附位置照片 → 入队等待用户确认三小时 → 仍未确认才平台代审 → 通过直接结算。用户确认则提前结算并退出队列；不通过不付款，到期不自动放款。例：18:00 提交，19:00 用户确认则 19:00 触发结算并出队；若一直未确认，则 21:00 才进入可代审阶段，21:20 审核通过即触发结算。

## 4. 后台审核与申诉（内部执行说明）

配送资格由平台后台审核，通过后开通接单权限；自动检查可辅助检查缺项、重复身份和限制状态，不因材料齐全自动通过。最终材料清单与资格审核时效仍待落实。

建议核验姓名、学校／校区、学号、经验证的手机号及学生身份证明；保留审核结果和必要记录，原始材料的保存期限与访问范围另定，不在本草案中新增身份证或家人信息收集。

资格流程：提交申请 → 后台审核 → 通过／需补充材料／未通过并说明原因。特殊送达队列分为“三小时内等待用户确认”和“已到期待人工代审”；前者不进行代审，用户确认时撤销任务。后台审核通过前核对最新确认与异议状态，只允许一次结算。资格、代审及申诉处理时效分别待落实，不沿用旧版两小时审核承诺；不建立在线客服系统。

十五分钟宽限只用于接单限制判断，保留原时限和实际迟到记录。宽限前点已送达的正常订单先等用户确认，特殊照片先等三小时再代审，不把用户确认等待或后台耗时认定为配送者违规。单方点击不证明真实交付，无照片未确认的核实方式见 Q-08。同一订单一次有效违规只计一次，累计两次封号，正常完成不清零；申诉成立撤销记录并重算。

## 5. 展示与待完善事项（内部）

- 用户版在付款前、配送者版在接单前展示，重要规则不得仅藏在协议链接里；订单内可回看当时的说明。完整说明入口使用本文件相应部分，后续再拆分独立规则文档。
- 正常送到后先点已送达，再由用户确认；无照片且用户一直未确认时，先联系用户，不自动转照片代审或自动放款，后续证据核实方式见 Q-08，不强迫补拍、摆拍。
- 十五分钟宽限、十五天接单限制及累计两次有效违规封号保留；正常待确认和特殊照片三小时等待／代审与接单限制分别记录，及时申报先待核实，不将用户未确认直接当作未送达。
- 配送资格由平台后台审核已确定，材料、人员及时效待落实；送达代审从特殊提交满三小时后开始，代审处理时限、补件及申诉时效待细化，不默认审核通过或无限延期。协商不成仍按取消、交接和重发规则处理，不引入在线客服。
- 全程优先沟通，但无需等待协商结束才能提交交付异议、暂停结算。争议资金处理及外部条款审查仍对应 Q-10；三个小时不表示其他合理反馈或请求自动失效。

- 无放置授权且用户失联时，不默认任意放置。照片审核不能代替用户约定，相关处置仍需明确。
