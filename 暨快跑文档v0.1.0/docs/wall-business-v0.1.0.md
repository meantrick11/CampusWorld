# 暨快跑 · 校园墙模块业务文档

版本：0.1.0。日期：2026-09-21。状态：已确认方向与待定业务细节，尚未实现。规则编号：CW-BR；未决事项：CW-Q。

## 1. 项目背景与业务目标

### 1.1 背景与问题

用户希望校园墙采用类似微博或 QQ 空间的发帖交流方式，支持文字、图片和视频，内容不限于失物招领或求助；只要符合内容规则，日常分享、讨论、吐槽、表白和活动信息等都可发布。该方向来自用户需求，尚未验证实际投稿与互动规模。

### 1.2 产品定位

**以稳定账号身份发布校园内容、交流和建立联系的信息社区。** 不提供完全匿名投稿模式，不是只能由管理员代发的投稿墙，也不承担帖子中活动或约定的履约保障。外部产品名称只说明交流形式，不代表复制其全部功能或当前规则。

| 问题 | 业务目标 |
|---|---|
| 有内容想分享或有问题想交流 | 允许普通注册用户自行发帖 |
| 文字不足以表达现场与经历 | 支持文字、图片、视频内容 |
| 希望对内容作出反馈 | 支持点赞、评论、回复、收藏、关注用户、分享链接，暂不做站内转发 |
| 完全匿名造成身份难以识别 | 发帖与账号关联，显示昵称、头像，修改有七天冷却 |
| 发布过滤仍可能遗漏违规内容 | 举报后审核决定是否展示，支持申请复核；AI 为后续可选方式 |

## 2. 业务流程

### 2.1 发帖与交流

用户编辑文字／图片／视频 → 提交过滤 → 通过后公开 → 其他用户浏览与互动 → 作者收到相关反馈并可回复 → 持续交流或管理帖子。

| 环节 | 业务动作 | 结果 |
|---|---|---|
| 创作 | 编辑正文、上传图片或视频 | 待提交内容；混合形式与容量上限待定 |
| 过滤 | 检查发布内容 | 通过后公开；疑似、失败和未通过路径按共用规则细化 |
| 发现 | 浏览公开内容，进入具体帖子 | 看到作者身份、内容及允许公开的互动 |
| 互动 | 点赞、评论、回复、收藏、关注用户、分享链接 | 互动与账号关联，不生成站内转发动态 |
| 私下联系 | 对作者或其他用户申请站内私聊 | 对方回复前只能发送一条消息 |
| 内容维护 | 作者可随时管理自己的帖子，包括编辑、删除；不能删除别人的评论 | 编辑重新过滤的细节待定；平台按审核决定处理违规内容 |

### 2.2 举报与审核

发现疑似违规 → 举报具体帖子或互动内容 → 审核决定是否继续展示 → 若决定下架，执行下架并通知作者原因。用户可以申请复核；AI 为以后可尝试引入的方式，不是首期必需能力。

已有过滤不替代举报流程。被举报不等于已确认违规或立即下架，由审核决定。决定前如何展示、审核与复核时效、后续 AI 分工待定。

### 2.3 内容失效与其他异常

普通分享帖不要求“完成”或“解决”；失物招领、求助、活动等时效性内容可考虑单独增加“已解决／已结束”标记，尚未确认，不能强迫所有帖子都走任务状态。

视频上传或处理失败时，建议允许重试且不生成空白公开帖；媒体处理、过滤和公开是不同环节。作者删除、平台下架后，评论、分享链接及消息中引用如何展示需同步定义，不能通过引用继续传播已下架原文。首期不做站内转发。

## 3. 范围与角色

### 3.1 内容范围

已确认允许文字帖、图片、视频，不限定少数校园事务分类。内容须符合平台规则，暴力、色情等违规内容不允许；具体过滤边界另行形成规则清单。对不同类型采用话题或分类只是待定组织方式，不据此缩窄已确认的内容范围。

### 3.2 参与角色

| 角色 | 业务职责 |
|---|---|
| 作者 | 使用账号发布内容、回应互动、维护自己的帖子 |
| 浏览／互动用户 | 阅读、参与交流、申请私聊、举报问题内容 |
| 平台 | 提供发布、内容发现、互动、消息与治理能力 |
| 审核方 | 决定被举报内容是否继续展示，下架通知原因，受理复核；AI 为后续可选方式 |

## 4. 业务规则

### 4.1 发布与身份

| 编号 | 状态 | 规则 |
|---|---|---|
| CW-BR-01 | 已确认 | 任何注册用户都能发布，不以学生认证或配送审核作为前置条件。 |
| CW-BR-02 | 已确认 | 允许文字、图片、视频，不将视频延后或仅限图文；同帖图文／视频混排方式、数量和时长上限待定。 |
| CW-BR-03 | 已确认 | 内容只要符合规则即可发布，不限定为求助、失物招领或活动通知。 |
| CW-BR-04 | 已确认 | 作者使用账号昵称、头像，不提供完全匿名模式。首次登录不计冷却；昵称和头像各有一次初始修改机会，修改成功后各自开始七天冷却，后续修改分别重新计时，遵循 INF-BR-03。 |
| CW-BR-05 | 待定建议 | 评论、回复等也显示账号身份，不使用临时匿名身份；昵称修改不切断既有内容与账号的关联。 |
| CW-BR-06 | 已确认原则 | 发布前过滤，被举报后由审核决定是否继续展示，下架通知原因，并允许申请复核；AI 为后续可选方式，遵循 INF-BR-10～15。 |

### 4.2 互动与联系

| 编号 | 状态 | 规则 |
|---|---|---|
| CW-BR-07 | 已确认 | 首期支持点赞、评论、回复、收藏、关注用户、分享链接，暂不做站内转发。分享链接用于访问原内容，不产生新的站内转发帖。 |
| CW-BR-08 | 待定建议 | 点赞可取消，同一账号不重复累计；评论与回复关联具体帖子及被回复对象，不因回复自动开放双方私聊。 |
| CW-BR-09 | 已确认权限／其他细节待定 | 帖子作者不能删除别人的评论；发现问题可举报交由审核处理。建议评论和回复同样经过过滤；评论媒体类型、回复层级、能否关闭评论、评论者能否删除自己的评论待定。 |
| CW-BR-10 | 已确认 | 站内私聊遵守一条申请消息限制，只有对方回复后才能继续发送。帖子公开互动不能默认替代私聊回复。 |
| CW-BR-11 | 待定建议 | 评论、回复及审核结果可通知相关用户；点赞、关注通知是否聚合、是否可关闭待定。收藏是否仅本人可见待定。 |
| CW-BR-12 | 已确认分享范围／其他细节为建议 | 分享链接允许未登录浏览公开内容，互动和私聊必须登录；已下架内容不因分享而继续公开。建议关注、收藏可取消且不重复累计，关注不直接视为同意私聊。 |

### 4.3 内容维护与管理

| 编号 | 状态 | 规则 |
|---|---|---|
| CW-BR-13 | 已确认作者权限／处理细节待定 | 作者可随时管理自己的帖子，包括编辑或删除，但不能单独删除别人的评论。建议编辑后重新过滤；审核期间旧版展示、删除整帖后关联评论的展示及举报记录保留待定。 |
| CW-BR-14 | 待定建议 | 普通帖子不设置成交或完成状态，不统一强制过期；时效性内容是否增加已解决／已结束标记待确认。 |
| CW-BR-15 | 已确认审核与复核／处罚待定 | 被举报内容由审核决定是否继续展示；决定下架时通知作者原因，用户可申请复核。具体复核流程、账号处罚及周期待定；不把内容下架自动等同于封号。 |
| CW-BR-16 | 已确认 | 帖子中的活动、赠送、交易或其他约定由用户自行协商，平台不为其真实性、付款或履约提供服务保障。 |

## 5. 业务状态与平台边界

内容状态建议如下，具体失败和复核处理仍待定：

| 状态 | 展示含义 | 后续处理 |
|---|---|---|
| 草稿 | 未提交公开 | 编辑或提交 |
| 过滤中 | 尚不可公开 | 等待结果或处理失败 |
| 过滤未通过 | 本次内容不公开 | 申请复核，或按原因修改后重提 |
| 已公开 | 可被允许的用户浏览与互动 | 编辑、删除或举报复核 |
| 平台下架 | 按审核决定不再公开展示 | 通知作者原因，允许申请复核 |
| 作者删除 | 不再作为正常帖子展示 | 引用展示及记录保留方式待定 |

举报处理中单独记录，不一律直接改成违规下架。无业务付款、订单履约或资金结算状态。信息发布、获赞、被分享或审核通过均不构成平台对内容真实性的保证。
