# 交给 Claude Code 的执行提示词

复制以下内容发送给 Claude Code，并让它访问整个 1.0.0 文档目录。

```text
请根据当前工作区的 1.0.0 文档，实现“暨快跑”纯公益校园信息发布小程序。

先读取：
1. 1.0.0/implementation/README.md
2. 1.0.0/implementation/execution-plan.md
3. 1.0.0/implementation/contracts.md
4. 1.0.0/implementation/progress.md
5. 1.0.0/README.md 及上述计划引用的业务文档

如果文档位于 specs/1.0.0，则以该目录为 SPEC_ROOT。先检查当前代码和说明文件；没有应用时默认创建 jirun/，已经有代码时不要覆盖或重复初始化。把实际 APP_ROOT、SPEC_ROOT 写入进度记录。

执行路线采用普通 uni-app Vue 3 + JavaScript + uniCloud + uni-id-pages + uni-admin + uni-ui；优先评估 uni-starter，聊天验证并复用 uni-im。不要改成 Java 微服务、商城或独立原生 App。按官方文档核实实际兼容版本、插件扩展点和部署方式，记录锁定版本与许可证，不杜撰框架接口。

按 T01～T12 顺序执行，先完成框架、规则和接入验证，再扩展业务。关键业务规则先写能暴露错误的测试，再实现并运行。每个任务都要提交：变更文件、执行命令、真实结果、剩余阻碍，并更新 implementation/progress.md。已有 Git 仓库时按任务提交自己的变更；没有 Git 时记录检查点，不擅自覆盖或整理别人的变更，不推送远端。

严格遵守：平台对用户完全免费，不做平台支付、钱包、抽成、充值、提现、会员、推广收费或捐款。用户之间可以自行协商价格。保留取送、闲置/求购、校园墙图文视频，以及校园墙点赞、评论、回复、收藏、关注和分享。不要因赶进度删掉视频。

私聊在对方回复前只能发送一条，按账号对在服务端执行；换信息、删会话、撤回、并发和重试不能绕过。审核、拉黑、下架、数据访问权限必须在服务端执行，不能只隐藏前端按钮。不能用管理员密钥或客户端传入的用户 ID 代表当前用户。

contracts.md 中的“开发默认值”可以用于本地实现，但不能标记成已获得业务确认；上线前确认清单继续保留。如果缺少 AppID、服务空间、工具或凭据，一次列清真实阻碍，继续可完成的规则、页面和测试，不能把 mock 结果说成真实联调通过。密钥只进入本地忽略文件或云端配置，不要求把密钥发到聊天，不写进文档、日志和 Git。

如果本机有 executing-plans 或 subagent-driven-development 技能，按适用技能执行；没有这些技能时，直接按计划逐项执行，不因缺少技能停工。不要求使用特定模型或必须创建子代理。

不要每完成一小步就要求重新批准。按已授权的实现范围持续推进。只有实际需要项目负责人提供外部条件、改变核心范围、开通付费资源或正式发布时，才说明具体事项。真实联调条件未满足时不能将相关任务勾选完成。

完成后给出：本地启动方法、微信开发者工具打开路径、管理后台入口、测试账号准备方式（不包含密码）、已通过的自动测试与真机项目、未完成项及上线前检查清单。当前先从 T01 开始。
```
