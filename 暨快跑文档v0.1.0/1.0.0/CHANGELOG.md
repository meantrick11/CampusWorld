# 1.0.0 版本变更说明

日期：2026-09-25。

## 本版决策

根据本次要求，将项目调整为纯公益信息发布平台，平台不收取任何费用。用户进一步明确：允许用户之间自行协商费用。因此保留取送报酬、二手价格与预算的表达，同时将平台业务改为免费发布、发现、联系和信息管理。

## 与 0.1.0 的差异

| 方面 | 0.1.0 | 1.0.0 |
|---|---|---|
| 平台定位 | 信息、订单与交易支付流程并存 | 纯公益信息发布与联系 |
| 收费方式 | 是否抽成及收费方式待定 | 明确不收取任何平台费用，无商业收费入口 |
| 用户费用 | 平台内支付，确认后结算 | 双方自行协商及处理，平台不经手 |
| 取送流程 | 发布支付、接单、取送、确认和结算 | 发布、联系、协商、维护信息状态 |
| 配送审核 | 接单资格、送达照片代审、超时处罚 | 取消平台配送管理，采用账号与内容治理 |
| 二手数量 | 付款占用、确认售出、退款释放 | 发布者维护剩余数量，不自动锁定库存 |
| 结束状态 | 与交付确认及资金流转相关 | 仅表示发布者反馈，不触发资金操作 |
| 校园墙 | 图文视频和基础互动 | 保留，并统一免费原则 |
| 共用能力 | 账号、私聊、过滤、举报、复核 | 保留，与纯信息模式一致 |
| 产品页面 | 包含支付、订单与结算 | 改为广场、发布、详情、消息、我的及内容治理 |
| 衡量目标 | 含支付与结算进展 | 有效信息、回应、用户反馈及治理质量 |
