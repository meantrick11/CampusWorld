# 暨快跑 · 校园取送信息业务

版本：1.0.0｜日期：2026-09-25｜状态：纯公益信息发布业务基线。

## 1. 定位与角色

校园取送板块集中展示快递代取、外卖取送及物品搬送需求。平台免费提供信息和联系渠道；用户自行判断是否帮助、能否完成，以及是否约定报酬。

| 角色 | 职责 |
|---|---|
| 发布者 | 描述真实需求、回应联系、维护信息状态 |
| 联系者 | 阅读需求、主动联系，自行评估携带能力和时间条件 |
| 平台 | 提供发布、浏览、私聊、内容治理与必要记录 |

平台不组织配送队伍，不派单，不承诺有人响应或按时送达。不设置配送接单资格或收取认证费用；发布和联系遵守共用账号规则，不代表平台已认证对方的身份或能力。

## 2. 主流程

免费发布需求 → 内容过滤 → 公开展示 → 有意向者发起联系 → 发布者回复 → 双方自行协商物品、时间、交接和报酬 → 发布者标记已联系／已完成／已关闭。

| 环节 | 规则 |
|---|---|
| 发布 | 填写物品类别、大小、件数、起终区域、时间要求及说明；可表达报酬意向或无偿求助 |
| 浏览 | 校园各区域的信息可浏览，不按用户所在区域隔离信息 |
| 联系 | 使用共用私聊规则，对方回复前最多一条申请消息 |
| 协商 | 双方自行约定是否承接、实际位置、取件配合、交接和费用 |
| 维护 | 发布者按实际情况更新需求状态，失效时及时关闭 |

## 3. 业务规则

本版重新定义 BR 编号，仅在 1.0.0 文档内引用。

| 编号 | 规则 |
|---|---|
| BR-01 | 发布取送信息及后续联系均免费，不产生平台交易订单或待支付记录。 |
| BR-02 | 报酬由双方自行协商，可为无偿；平台不设置参考收费表、最低价或抽成比例。公开报酬仅是意向，不触发付款。 |
| BR-03 | 公开内容描述物品、起终区域和时间要求，不公开电话、取件码、动态验证信息或精确寝室号。必要信息由本人在确认沟通对象后私下提供。 |
| BR-04 | 联系者自主判断携带能力、时间及实际通行条件；平台不核验是否顺路，不保证楼栋可进入。 |
| BR-05 | 同一需求可收到多个联系意向，私聊不等于自动接受委托，也不产生排他承接权。发布者应及时更新已联系状态，避免重复安排。 |
| BR-06 | 取件时间、动态码配合及异常等待由双方自行协商，平台不强制五分钟到站区间或三分钟自动终止流程。 |
| BR-07 | 需求条件变化应主动告知已有联系人，私下约定由双方再次确认。修改帖子不代表对方已同意变更。 |
| BR-08 | 发布者可关闭尚有效的需求；已经约定的交接仍须双方协商处理。信息关闭不代表物品已归还或费用已退回。 |
| BR-09 | 标记已完成仅表示发布者反馈，不要求平台确认收货、审照片或等待三小时，不触发资金操作。 |
| BR-10 | 平台不依据送达时限自动执行十五天接单限制或累计两次配送违规封号；账号处置依据统一内容治理规则及复核结果。 |
| BR-11 | 发现虚假信息、骚扰或其他违规内容可举报；平台处理内容及账号问题，不代收、划扣、退还或裁定双方价款。 |
| BR-12 | 平台不提供配送、保险、替补或兜底赔付承诺。信息下架、举报或已完成标记均不能代替双方对物品与费用的处理。 |

## 4. 信息状态

内容审核状态与需求状态分别记录；只有审核允许公开且需求有效时，才作为可联系需求展示。

| 状态 | 含义与后续动作 |
|---|---|
| 寻找帮助 | 当前仍需要回应，发布者可编辑、关闭或标记已联系 |
| 已联系 | 发布者已与人沟通或达成安排；不等于平台已确认承接，后续可完成、关闭或重新寻找 |
| 已完成 | 发布者反馈需求已完成，不代表平台核实交付 |
| 已关闭 | 已取消、不再需要或时效已过，不再作为有效需求推荐 |

以上为本版信息状态设计。截止时间和自动过期细节列入[待确定问题](pending-v1.0.0.md)，未落实前不承诺自动关闭。平台下架状态优先于发布者的有效状态，不能通过更改需求状态绕过审核。

## 5. 异常处理

无人回应时，发布者可修改信息或关闭需求；平台不自动加价或补派。沟通失败、迟到、临时变更或无法交接时，双方自行沟通；已经取得物品，应优先明确返还或交接安排，不能把关闭信息当作处理完成。

如涉及内容违规，可提交举报并补充相关说明，平台按共用规则审核并告知结果。私下报酬和物品争议由双方自行处理，平台可在已明确的权限和记录范围内提供信息协助，不承诺已有专职客服或完整争议仲裁能力。
