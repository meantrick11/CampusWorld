# 暨快跑 · 二手信息业务

版本：1.0.0｜日期：2026-09-25｜状态：纯公益信息发布业务基线。

## 1. 定位与范围

提供闲置、求购及相关供需信息的免费发布和联系渠道。用户可以自行商议商品价格、数量、交付及付款方式；平台不收取任何费用，也不经手交易资金。允许无偿赠送，但不强制所有商品免费。

二手范围不限书籍。沿用原版广泛供需信息方向，不因名称预先排除全新、虚拟、票券或服务类信息；这些类型的具体允许范围、字段与过滤条件须在上线前明确，未明确的类型不默认开放。商家发布同样遵守内容规则，不获得付费入驻、广告或排名特权。

## 2. 主流程

闲置：发布信息 → 过滤通过 → 他人浏览并联系 → 双方自行协商 → 发布者更新剩余数量／标记已售出或已下架。

求购：发布物品需求、数量与预算意向 → 过滤通过 → 供货者联系 → 双方自行协商 → 求购者更新需求／标记已求得或已关闭。

站内联系不生成购买订单、资金记录或库存预留；平台不要求先付款或确认收到后放款。

## 3. 业务规则

本版重新定义 SH-BR 编号，仅在 1.0.0 文档内引用。

| 编号 | 规则 |
|---|---|
| SH-BR-01 | 任何符合共用账号规则的注册用户可免费发布，不收取发布费、成交佣金或联系费用。 |
| SH-BR-02 | 闲置信息包含标题、描述、类别、数量和价格意向；图片等必填细节待定。数量为发布者声明，需及时维护。 |
| SH-BR-03 | 求购信息描述所需物品、数量及要求，可填写预算，不强制持有实物照片。 |
| SH-BR-04 | 可表达明确价格、面议或赠送；价格和预算仅作为信息，不构成平台保证的成交价。 |
| SH-BR-05 | 联系遵守共用私聊限制，同一对账号未回复前最多一条申请，换商品不能重置额度。 |
| SH-BR-06 | 用户自行协商交付与费用；平台无购买、支付、确认收货、退款、结算或提现入口。 |
| SH-BR-07 | 联系、收藏及私下付款均不自动占用或扣减平台数量；剩余数量由发布者维护，不保证实时库存。 |
| SH-BR-08 | 发布者将剩余数量改为零时，信息退出有效供给列表；结束原因为售出、赠送完毕或关闭时应准确选择，不把数量归零一律当作平台核实售出。 |
| SH-BR-09 | 求购者自行维护尚需数量，已满足时标记已求得，不由平台汇总付款或供货订单。 |
| SH-BR-10 | 下架或删除停止公开展示，不代表私下约定取消或费用已经退回。既有会话按共用权限和保留规则处理。 |
| SH-BR-11 | 重新发布须满足内容审核及账号权限要求，不能用修改数量恢复被审核下架的内容。 |
| SH-BR-12 | 不建立交易评价或成交信用分；信息标记为已售出、已求得不构成平台真实性背书。 |
| SH-BR-13 | 发布过滤、举报、下架通知及复核使用共用规则，举报处理不触发退款或赔付。 |

## 4. 信息状态与数量

| 对象 | 状态 | 含义 |
|---|---|---|
| 闲置 | 在售／可赠送 | 发布者声明仍有物品可联系 |
| 闲置 | 已售出／已赠出 | 发布者反馈已处理完毕 |
| 闲置 | 已下架 | 主动关闭或数量归零后暂未说明处理结果 |
| 求购 | 求购中 | 发布者声明仍有需求 |
| 求购 | 已求得／已关闭 | 需求已满足或不再继续 |
| 内容审核 | 过滤中／未通过／通过／平台下架 | 控制公开展示，独立于供需状态 |

示例：发布者有两本书，收到三人私聊时仍显示其声明的两本；私下交付一本后，由发布者改为一本；全部处理完后改为零并选择已售出或已赠出。系统不推算聊天对象是否付款，不设置付款占用、退款释放及自动补货。

## 5. 发现、异常与边界

支持按闲置／求购及分类发现信息，关键词搜索和具体筛选范围见[页面需求](requirements-v1.0.0.md)。收藏、公开留言、关注等二手专属能力仍待确定，不因校园墙已有这些能力而直接视为已确定。

信息失效、描述不符、对方未回应时，用户可停止联系并反馈问题；涉及虚假、骚扰或违规内容可举报。物品状况、最终价格、交付、退换或其他约定由双方自行核实和协商，平台不提供验货、保真、担保或兜底赔付。
