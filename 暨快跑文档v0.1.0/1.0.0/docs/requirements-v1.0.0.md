# 暨快跑 · 产品需求与页面设计

版本：1.0.0｜日期：2026-09-25｜状态：需求基线与页面草案，尚未实现。

## 1. 设计口径

平台是完全免费的校园信息发布项目，保留取送、二手和校园墙。平台只提供信息与联系，用户之间自行协商费用。所有页面、提示和后台操作均遵守[平台规划](platform-planning-v1.0.0.md)的免费边界。

本版重新定义 REQ、PG、SC 编号，不继续使用旧版交易页面与验收条件。下述是本版需求设计，不意味着每项细节已经由用户单独确认。待定参数统一收录于[待确定问题](pending-v1.0.0.md)。

## 2. 功能需求

| 编号 | 能力 | 规则来源 | 验收重点 |
|---|---|---|---|
| REQ-01 | 免费使用 | 平台规划第 2 节 | 发布、联系和管理不要求支付，不出现收费解锁或抽成 |
| REQ-02 | 账号与资料 | INF-BR-01～04 | 账号关联内容；昵称和头像各一次初始修改机会，其后各自七天冷却 |
| REQ-03 | 分类浏览与发现 | 各板块范围 | 展示有效且允许公开的信息；关键词搜索、筛选细节待定 |
| REQ-04 | 取送信息发布 | BR-01～04 | 表达物品、区域、时限和报酬意向；不生成订单 |
| REQ-05 | 二手信息发布 | SH-BR-01～04 | 支持闲置和求购，数量明确，价格允许面议或赠送 |
| REQ-06 | 校园墙发布与互动 | CW-BR-01～13 | 文字、图片、视频；点赞、评论、回复、收藏、关注、分享；无站内转发 |
| REQ-07 | 站内私聊 | INF-BR-05～09 | 对方回复前限一条申请消息，跨内容入口共享限制 |
| REQ-08 | 信息维护 | BR-05～09；SH-BR-07～11 | 作者编辑、关闭、标记进展；不触发资金或库存占用操作 |
| REQ-09 | 内容过滤与举报 | INF-BR-10～15 | 过滤通过后公开，举报进入审核，下架通知原因并可复核 |
| REQ-10 | 隐私与分享 | INF-BR-01；BR-03 | 分享只展示允许公开内容；私聊、取件码和私密资料不公开 |
| REQ-11 | 平台说明与反馈 | 使用说明 | 明示平台免费、双方自行协商、信息服务范围及举报入口 |

## 3. 页面范围

基础导航保留“广场、消息、我的”。发布按钮进入板块选择及对应表单。

| 编号 | 页面或区块 | 内容和动作 |
|---|---|---|
| PG-01 | 广场 | 取送、二手、校园墙分类；有效信息列表及发现入口；不提供付费排名 |
| PG-02 | 发布信息 | 选择板块，填写字段，上传对应媒体，预览并提交过滤；按钮为“发布”，无支付步骤 |
| PG-03 | 信息详情 | 作者、内容、时间、状态、报酬或价格意向；联系、分享、举报；自有内容显示管理动作 |
| PG-04 | 消息列表与会话 | 私聊申请、回复、系统通知、拉黑与举报；关联原信息及其当前可见状态 |
| PG-05 | 我的 | 昵称头像、我的发布、适用的收藏与关注、反馈及规则；无余额、收益或提现 |
| PG-06 | 我的发布与编辑 | 查看审核进度，编辑、删除、关闭、更新数量和进展；区分内容审核与需求状态 |
| PG-07 | 校园墙详情 | 图文视频及六项基础互动；作者不能单独删除别人的评论 |
| PG-08 | 举报与复核 | 选择对象及原因、补充说明、查看处理结果、申请复核；入口免费 |
| PG-09 | 后台内容管理 | 审核内容及举报、记录决定、通知原因、处理复核；无支付审核、配送放款或资金操作 |
| PG-10 | 关于平台 | 公益免费声明、信息服务边界、使用说明和反馈方式 |

“联系发布者”表示发起沟通，不使用“立即购买”“支付后接单”等文案。取送进度使用信息状态，不出现配送订单号、平台履约倒计时或到账提示。金额旁应注明“由双方自行协商，平台不收取费用”。

## 4. 状态与异常

发布状态、供需进展、举报状态和私聊权限分别记录。过滤未完成或媒体处理失败时，不把内容作为成功公开；失败时保留可修改的内容并提供后续处理提示，具体重试方式待定。

下架、删除或权限受限的信息不能从分享链接、列表缓存或会话引用继续公开原文。原会话显示相应状态，历史消息的保留期限和访问规则另行落实。作者更新信息不能重置私聊限额，也不能解除平台的审核限制。

## 5. 验收场景

| 编号 | 场景 | 预期结果 |
|---|---|---|
| SC-01 | 用户发布有报酬的取送需求 | 可免费提交；通过过滤后展示；无平台收费、订单支付或押金 |
| SC-02 | 用户发布赠送或面议的闲置 | 均可表达，价格意向不触发支付流程 |
| SC-03 | 同一人先从商品 A 私聊，再从帖子 B 私聊同一作者 | 对方未回复时不能发送第二条申请；已读、点赞和公开评论不解除限制 |
| SC-04 | 私聊对方回复后继续沟通 | 可正常聊天；费用由双方自行协商，无平台支付或结算入口 |
| SC-05 | 二手发布数量为二，收到多个联系意向 | 数量不会因私聊自动减少或锁定；发布者自行更新剩余数量 |
| SC-06 | 作者将剩余数量改为零 | 退出有效供给展示；不生成确认收货、退款或结算记录 |
| SC-07 | 取送发布者标记已完成 | 只更新信息状态，不触发照片代审、三小时等待或放款 |
| SC-08 | 用户举报帖子 | 举报进入审核，不将举报本身直接认定为违规；决定下架后通知原因并提供复核 |
| SC-09 | 游客访问公开分享链接 | 可浏览公开内容；互动和私聊需登录，下架或私密内容不能显示 |
| SC-10 | 首次修改昵称后立即修改头像 | 各有独立初始机会；昵称冷却不阻止头像首次修改 |
| SC-11 | 视频上传或过滤失败 | 不产生空白公开帖，提示可处理的失败状态 |
| SC-12 | 作者删除整帖或编辑被下架的信息 | 不绕过治理；整帖关联内容的可见性按最终规则执行；作者不能单独删他人评论 |
| SC-13 | 用户浏览全部前后台页面 | 不存在收费会员、推广购买、充值、提现、捐款、交易支付或资金结算功能 |

本表是后续开发验收要求，不是已经执行通过的软件测试结果。

## 6. 不纳入本版的能力

平台支付、代收代付、资金托管、钱包、退款、结算、提现、付费推广和付费会员均不纳入本版。旧版支付成功后的库存占用、送达照片代审、资金争议冻结及配送超时处罚流程同时退出本版需求。

专送调度、实时轨迹、平台担保、交易信用评分和完整在线客服系统也不属于当前范围。技术实现和上线组合另行确认，不通过本轮文档修改宣称已经完成开发。
