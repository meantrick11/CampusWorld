# 暨快跑 · 平台使用说明

版本：1.0.0｜日期：2026-09-25｜状态：页面文案草案，与公益信息发布定位一致。

## 1. 关于平台

暨快跑是纯公益校园信息发布平台。发布、浏览、联系和内容管理均免费，平台不收取服务费、抽成、会员费、认证费、保证金或推广费用，也不设置充值、打赏和捐款入口。

你可以发布取送需求、闲置或求购信息，以及校园生活内容。用户之间可自行商议二手价格、取送报酬和交付方式，也可选择赠送或无偿帮助。平台不经手双方资金，不提供代收、托管、退款或结算。

## 2. 发布与联系提示

请准确填写需求和物品信息，并及时更新有效状态。公开页面不要填写取件码、动态验证信息、电话号码或精确寝室号；必要信息在确认沟通对象后私下提供。

你可以向对方发起一条私聊申请，收到对方回复后继续交流。换商品、换帖子或删除会话不会增加申请次数。内容中的价格、预算或报酬是发布者意向，具体条件由双方自行商议。

信息通过过滤并不代表平台已经核验发布者身份、物品情况或履约能力。你可以举报虚假、骚扰或其他违规内容，平台会按内容规则处理，并在决定下架时告知原因；相关用户可申请复核。

## 4. 信息结束与问题反馈

“已联系”“已完成”“已售出”“已求得”等状态由发布者维护，仅表示其反馈的进展，不代表平台确认了付款或交付。关闭、删除或下架信息不会自动取消双方已作出的约定，也不代表费用已经退还。

物品交接、费用或其他约定发生变化时，请及时与对方沟通。若涉及平台内容违规，可通过举报入口反馈。平台提供信息及内容治理服务，不承诺配送、验货、保险或兜底赔付，也不以“公益免费”为由取消自身应承担的责任。
