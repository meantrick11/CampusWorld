# 暨快跑 · 信息模块共用业务规则

版本：1.0.0。日期：2026-09-25。状态：业务设计，尚未实现。适用于取送信息、二手信息与校园墙。

**已确认**为用户明确决定；**待定建议**只用于讨论，不能作为已批准的实现要求。规则以 INF-BR 编号，各模块文档直接引用，避免出现不同的私聊和账号规则。

## 1. 平台边界

平台是纯公益信息发布项目。发布、浏览、联系、互动及内容管理均免费，不收取任何费用，不提供付费推广、会员、认证或联系特权，也不设置充值、打赏或捐款入口。

用户可以自行协商二手价格、取送报酬及交付方式；平台不经手交易资金，不提供平台支付、代收代付、托管、退款、结算或提现。平台保留信息及联系能力，不生成交易订单，也不承担配送、验货、保真或兜底赔付服务。

取送与二手的进展、数量由发布者维护，表示其反馈的信息，不代表平台核实了付款或履约。校园墙普通帖子不设置交易状态。举报、下架和复核处理内容是否展示，不处理资金。

## 2. 账号与身份

| 编号 | 状态 | 规则 |
|---|---|---|
| INF-BR-01 | 已确认 | 任何注册用户都可发布，不要求先通过学生认证；本版不设置配送接单资格。分享链接允许未登录用户浏览公开内容，互动和私聊需要登录；该开放范围不包含私聊记录、非公开或已下架内容。发布仍需经过内容过滤及账号权限检查。 |
| INF-BR-02 | 已确认 | 用户拥有昵称、头像，发布和互动关联账号，不提供完全匿名身份或匿名发帖模式。昵称、头像不代表实名认证或交易可信保证。 |
| INF-BR-03 | 已确认／整改例外待定 | 首次登录不计入修改冷却；昵称、头像各有一次不受冷却限制的初始修改机会。某项初始修改成功后，该项开始七天冷却；以后每次修改成功都重新计算该项七天冷却。两项机会和冷却互不影响，各自满七天可再改。违规资料整改的处理待定。 |
| INF-BR-04 | 待定建议 | 内容归属关联稳定的账号标识，不能以可修改昵称判断是否同一人；昵称、头像也经过内容过滤。 |

## 3. 站内私聊

确认主线：选择联系对象 → 发送一条私聊申请消息 → 对方回复 → 双方正常聊天。

| 编号 | 状态 | 规则 |
|---|---|---|
| INF-BR-05 | 已确认 | 采用站内聊天，可以申请私聊；对方回复之前，发起者正常只能发送一条信息，不能连续追加。仅阅读消息不构成回复。 |
| INF-BR-06 | 已确认 | 限额按同一对账号关系计算，对方未回复前总共只能发送一条消息，没有等待若干天后重新申请的额度。切换商品、帖子或入口、删除本地会话、撤回消息均不能绕过这一总量限制。 |
| INF-BR-07 | 已确认原则／细节待定 | 对方回复后可继续聊天；正常聊天支持的文字、图片、视频类型与大小上限待定，不能从校园墙支持视频推导私聊也支持视频。 |
| INF-BR-08 | 待定建议 | 私聊申请关联发起时的商品或帖子，帮助接收方理解来意；原内容下架后，既有会话不自动删除，明确提示内容当前状态。 |
| INF-BR-09 | 已确认功能／作用范围待定 | 支持拉黑功能。建议拉黑后阻止被拉黑者继续私信；是否同时禁止评论、回复及查看内容，解除后的权限如何恢复，仍待确定。独立“拒绝申请”功能未确认；任何拒绝或解除拉黑均不能在对方未回复时重置单条消息限额。 |

私聊状态建议：未联系 → 申请待回复 → 已互相回复。拒绝／拉黑是另行定义的限制状态。发起者在待回复阶段只能等待，不能因为已读、系统通知、表情点赞或内容作者的公开评论而自动获得继续发送权限；具体哪些动作属于“回复”仍需细化。

## 4. 过滤、举报与复核

确认主线：提交内容 → 过滤 → 通过后公开；过滤遗漏的内容可被举报 → 审核决定是否继续展示 → 若决定下架，则执行下架并通知原因。用户可申请复核；AI 审核为后续可尝试引入的方式，不是首期已确定依赖。

| 编号 | 状态 | 规则 |
|---|---|---|
| INF-BR-10 | 已确认 | 发布最开始设置过滤机制，不能以“只是信息平台”为由完全不处理违规内容。暴力、色情等违规内容不允许发布；规则清单、阈值和具体识别方式待定。 |
| INF-BR-11 | 待定建议 | 文字、图片、视频及封面均进入过滤；过滤未完成不公开，技术失败不冒充通过。明确未通过时说明原因，允许修改后重新提交。疑似内容是否转人工／AI 待定。 |
| INF-BR-12 | 已确认 | 对过滤未覆盖、后续被举报的内容进行审核，由审核决定是否继续展示；以后可尝试引入 AI，不默认首期已采用 AI，也不预设 AI 自动封号。审核人员、时效及后续 AI 分工待定。 |
| INF-BR-13 | 已确认原则／记录细节为建议 | 举报本身不等于违规或自动下架；审核决定下架时执行下架，并通知作者具体原因。建议记录举报对象、原因、说明及处理状态。最终决定前的展示策略待定。 |
| INF-BR-14 | 已确认复核／处罚细节待定 | 用户可对过滤拦截或审核处理申请复核，复核受理不自动恢复展示。复核方式、时效和通过后的恢复条件待细化。反复违规账号的限制期限、累计规则待定，不设置配送履约处罚。 |
| INF-BR-15 | 待定建议 | 编辑已公开内容后，新版本重新过滤；审核对象关联具体版本，避免修改或删除内容绕过尚未完成的举报处置。旧版在审核期间是否展示待定。 |

审核状态与业务状态分开记录：例如商品仍被作者标记为“在售”，但因内容下架已不再公开展示。内容处理不修改用户自行约定的价款，平台没有退款流程。作者修改状态或数量不能绕过审核限制。

| INF-Q-03 | 过滤规则、疑似内容、失败重试、审核人员及时效；AI 为后续可选方式 | 公开发布前 |
| INF-Q-04 | 复核具体流程、账号处罚、审核决定前的展示、编辑版本及记录保留 | 举报治理启用前 |
| INF-Q-05 | 分享公开内容免登录浏览、互动和私聊需登录已确认；非分享入口的游客范围、消息及举报资料保留期限待定 | 对应能力启用前 |

## 6. 隐私与公益运行

公开页面不展示取件码、动态验证信息、电话号码或精确寝室号。私聊内容不因帖子被分享而公开；消息、附件和举报材料的访问权限及保留期限须在启用前明确。信息下架或删除后，分享链接和引用不能继续公开原文。

内容治理和运行资源由项目方组织，不通过收费豁免审核、扩大私聊额度或购买曝光。必要的防骚扰、内容容量及发布频率限制应对用户一致适用，具体参数待定。
