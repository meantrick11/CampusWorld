# 暨快跑 · 纯公益平台规划

版本：1.0.0｜日期：2026-09-25｜状态：文档基线，未声明已实现。

## 1. 定位与目标

暨快跑是纯公益的校园信息发布平台，免费提供发布、浏览、交流及内容管理能力。目标是减少校园信息分散，让需求更容易被看见，让用户自主建立联系。

本版“公益”指平台完全免费运营。用户可以发布有价格的闲置商品、有预算的求购信息及有报酬的取送需求，也可以选择赠送或无偿帮助。用户自行协商的费用不属于平台收入。

## 2. 免费原则

| 项目 | 1.0.0 规则 |
|---|---|
| 发布、浏览、搜索与联系 | 免费，不设付费次数或付费解锁 |
| 评论、点赞、收藏、关注及分享 | 已纳入范围的功能均免费 |
| 审核、举报、复核 | 免费，不以付款换取通过或恢复 |
| 会员、认证、入驻、保证金 | 不设置收费项目 |
| 抽成、佣金、服务费 | 平台均不收取 |
| 商业推广 | 不提供付费广告、付费置顶或竞价排名 |
| 充值、打赏、捐款 | 本版均无入口，不以公益名义收款 |
| 用户之间的费用 | 双方自行约定与处理，平台不经手资金 |

免费是本版本明确基线，不是限时促销或待定收费方案。所有内容适用相同的发布和治理规则，不能通过付款取得特权。

## 3. 板块范围

| 板块 | 提供的信息能力 | 完成方式 |
|---|---|---|
| 校园取送 | 发布物品、起终区域、时间要求、报酬意向；站内联系 | 双方自行协商，发布者更新需求状态 |
| 二手信息 | 闲置及求购，展示数量、描述、价格或预算 | 双方自行协商，发布者维护剩余数量和状态 |
| 校园墙 | 文字、图片、视频与校园交流 | 作者维护帖子，平台处理内容问题 |

保留三个板块，暂不新增独立校园互助板块。公益不等于所有帖子只能发布公益活动，也不将二手缩减为仅书籍或仅赠送。具体内容范围沿用各模块的规则；涉及特殊类型的发布边界仍需在上线前细化。

## 4. 共用流程与边界

发布者编辑内容 → 提交过滤 → 通过后公开 → 浏览者查看或发起私聊 → 对方回复后继续沟通 → 双方自行安排后续事项 → 发布者更新、结束或删除信息。

平台维护账号、信息状态、互动、消息和审核记录。信息状态表示发布者反馈的需求进展，不构成平台对付款、交付或真实性的确认。站内不建立交易订单、钱包、支付接口、资金账本、退款或结算流程，不派单、不代为确认收货，也不建立送达照片代审放款流程。

平台继续提供过滤、举报、下架通知与复核，公益运营不取消内容治理职责。账号、私聊及共享权限详见[共用规则](information-common-v1.0.0.md)。

## 5. 公益运营

服务器、域名、存储和审核投入由项目方自行安排，具体资源预算待落实，不向用户转嫁为平台收费。可根据实际资源设置对所有用户一致的内容容量和频率限制，不提供付费提高额度。

项目成效以有效信息量、联系回应、用户反馈的需求解决情况、重复使用及举报处理情况衡量。不以流水、抽成、会员转化或广告收入为目标，不将私聊或“已完成”标记当作经核实的成交记录。

## 6. 推进顺序

1. 完成发布字段、状态、隐私及审核规则，落实[待确定问题](pending-v1.0.0.md)。
2. 按已确认范围设计发布、浏览、消息、我的及后台治理页面；首次上线的板块组合另行确定。
3. 小范围验证信息发布、联系及内容处理能力，确认运行资源可持续。
4. 根据使用反馈调整分类、提醒和交互；新增能力继续遵守平台完全免费原则。

技术栈、数据库、接口和部署方式尚未确定。1.0.0 是文档版本，不是已上线版本的声明。
