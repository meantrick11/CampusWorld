# 暨快跑 · 纯公益信息发布平台

版本：1.0.0｜更新日期：2026-09-25｜状态：文档基线，尚未代表功能已实现或已上线。

**平台完全免费，帮助校园用户发布信息、发现需求和建立联系。用户之间可以自行协商二手价格、取送报酬及交付方式。**

平台不收取发布费、服务费、抽成、佣金、会员费、认证费、保证金或推广费用，也不设置付费置顶、付费解锁联系方式、充值、打赏和捐款入口。公益是平台的运营定位，不要求所有用户赠送物品或无偿提供服务。

本版本采用纯信息发布模式：免费发布 → 内容过滤 → 公开展示 → 站内联系 → 双方自行协商 → 发布者维护信息状态。平台不接入交易支付，不代收代付、托管、结算或退款。
